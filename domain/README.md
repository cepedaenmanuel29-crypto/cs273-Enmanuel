# Basketball Tournament Database

## Mission Statement

The purpose of this database is to help organize basketball 3v3 tournaments. It will keep information about players, teams, coaches, games, and statistics in one place.

## Mission Objectives

1. Keep the information for each player.
2. Keep the information for each team.
3. Keep track of coaches.
4. Keep track of the games played in the tournament.
5. Record player and team statistics.
6. Keep track of game results.
7. Keep a record of MVP players.

## Domain Description

This database is for basketball 3v3 tournaments. It will help organize players, teams, coaches, games, and results. Instead of having the information in different places, everything can be kept together and be easier to find.

The database can be used by the people organizing the tournament. They can see what players are on each team, when teams play, game results, player statistics, and who was selected as MVP. A relational database works well for this because players, teams, coaches, and games are all connected to each other.
