## Basketball 3v3 Tournament Database

My project is a database for organizing 3v3 basketball tournaments.

The database keeps track of players, teams, coaches, tournaments, games, scores, and player statistics.

I created seven tables and connected them using primary keys and foreign keys.

The ERD and the explanation of my design are inside the `erd` folder.
