# Field List

# Phase 2

1. Player ID – Unique number used to identify each player.
2. Player First Name – Stores the player's first name.
3. Player Last Name – Stores the player's last name.
4. Player Date of Birth – Stores the player's birth date.
5. Jersey Number – Stores the player's jersey number.
6. Team ID – Unique number used to identify each team.
7. Team Name – Stores the name of the team.
8. Coach ID – Unique number used to identify each coach.
9. Coach First Name – Stores the coach's first name.
10. Coach Last Name – Stores the coach's last name.
11. Coach Phone Number – Stores the coach's phone number.
12. Coach Email – Stores the coach's email address.
13. Tournament ID – Unique number used to identify each tournament.
14. Tournament Date – Stores the date of the tournament.
15. Tournament Location – Stores where the tournament takes place.
16. Game ID – Unique number used to identify each game.
17. Game Date – Stores the date of the game.
18. Game Time – Stores the starting time of the game.
19. Court Number – Stores the court where the game is played.
20. Team 1 ID – Identifies the first team playing in the game.
21. Team 2 ID – Identifies the second team playing in the game.
22. Team 1 Score – Stores the final score of the first team.
23. Team 2 Score – Stores the final score of the second team.
24. Player Points – Stores the points scored by a player.
25. Player Rebounds – Stores the rebounds made by a player.
26. Player Assists – Stores the assists made by a player.
27. Player Steals – Stores the steals made by a player.
28. MVP Player ID – Identifies the player selected as MVP.

# Calculated Field List

1. Winning Team – Calculated by comparing the final scores of the two teams.
2. Team Wins – Calculated by counting the games won by each team.
3. Team Losses – Calculated by counting the games lost by each team.
4. Win Percentage – Calculated using team wins and total games played.
5. Player Total Points – Calculated by adding all points scored by a player.
6. Player Average Points – Calculated by dividing total points by games played.
